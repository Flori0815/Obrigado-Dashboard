# obrigado-dashboard

Automatisch generierte, rein lesbare Veröffentlichung von Wiki, Wartungsplan
und offenen/erledigten Reparaturen aus dem privaten Repo
[`obrigado`](https://github.com/Flori0815/obrigado).

**Dieses Repo wird ausschließlich von einer GitHub Action überschrieben -
keine manuellen Änderungen hier vornehmen.**

Veröffentlicht per GitHub Pages unter:
`https://flori0815.github.io/obrigado-dashboard/` (sobald in den
Repo-Settings unter "Pages" als Quelle "Deploy from a branch" → `main` →
`/ (root)` eingestellt ist).

Enthält bewusst **keine** Kaufhistorie, Preise oder Personendaten.
